# 🌱 Roots — Social Networking Android App

**Roots** is a social networking Android application that helps users connect through events and a buddy-matching system. Built as a team project at San José State University.

## Features

- **Event Discovery & Creation** — Browse, search, and filter events by category (Social, Music, Sports). Create and host your own events with date/time selection.
- **Buddy System** — Swipe-based profile matching to find and connect with new people. Send buddy requests, view profiles, and manage connections.
- **User Profiles** — View and edit personal profiles with bio, interests, pronouns, location, and profile picture. Track upcoming events, hosted events, invites, and attendance history.
- **Friend Requests** — Send, accept, and decline buddy requests. View Buddies, Requests, and Blossoms (mutual matches).
- **Authentication** — User login and signup powered by Firebase.

## Tech Stack

- **Language:** Java
- **Platform:** Android (Kotlin DSL Gradle)
- **Backend:** Firebase Firestore & Firebase Auth
- **Image Loading:** Picasso
- **UI:** Material Design Components, Navigation Component
